# AegisOS Configuration Directory Structure

This directory contains system architecture specifications, environment profiles, and JSON schemas for AegisOS platform validation.

## Domain Partitioning

- `config/environments/` — Infrastructure environment profile definitions (development, staging, production).
- `config/schemas/` — JSON schemas for validating system declarations, platform capabilities, and contracts.
- `configs/` — Dynamic runtime operational profiles, service port registries (`ports.json`), and LiteLLM configuration profiles (`litellm/`).
